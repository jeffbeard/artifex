# Periodic table elements

All 118 elements, for use as project names or as roots for invented names. Load this file only when the user selects the periodic table word list.

## How to use

- **Match on meaning first.** The origin column is what makes an element name fit a project: `Dysprosium` ("hard to get") for a retrieval tool, `Technetium` ("artificial") for something synthetic, `Lanthanum` ("to lie hidden") for a secrets manager.
- **Match on properties second.** Noble gases suggest stability and isolation, alkali metals reactivity, transition metals strength and structure, lanthanides rarity, actinides power.
- **Symbols work as short names.** One and two letter symbols suit CLI commands and prefixes (`Au`, `Fe`, `Xe`). Say what the symbol stands for in the etymology.
- **Latin names are a second pool.** Several symbols come from Latin names that are less used than the English ones: Aurum (Au), Argentum (Ag), Ferrum (Fe), Cuprum (Cu), Plumbum (Pb), Stannum (Sn), Stibium (Sb), Natrium (Na), Kalium (K), Hydrargyrum (Hg), Wolfram (W).
- **Atomic numbers can carry meaning.** A version number, a count, or a founding year fragment can point at an element.
- **Sets give a naming scheme.** One group can name a family of related projects or releases, such as the noble gases or the four elements named after Ytterby.

## Groups

| Group | Members | Associations |
|---|---|---|
| Alkali metals | Li, Na, K, Rb, Cs, Fr | Reactive, fast, volatile |
| Alkaline earth metals | Be, Mg, Ca, Sr, Ba, Ra | Structural, foundational |
| Transition metals | Sc to Zn, Y to Cd, Hf to Hg | Strong, durable, catalytic |
| Lanthanides | La to Lu | Rare, hidden, specialised |
| Actinides | Ac to Lr | Powerful, heavy, unstable |
| Metalloids | B, Si, Ge, As, Sb, Te | In between, semiconducting |
| Halogens | F, Cl, Br, I, At, Ts | Sharp, reactive, purifying |
| Noble gases | He, Ne, Ar, Kr, Xe, Rn, Og | Stable, inert, isolated |
| Precious metals | Au, Ag, Pt, Pd, Rh, Ir, Os, Ru | Valuable, lasting |
| Named after Ytterby | Y, Tb, Er, Yb | A set of four from one village |
