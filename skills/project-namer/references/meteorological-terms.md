# Meteorological terms

Weather and atmosphere vocabulary, for use as project names or as roots for invented names. Load this file only when the user selects the meteorological word list.

## How to use

- **Match the phenomenon to the behaviour.** A front is a boundary, a jet stream is a fast channel, a squall is a sudden burst, an eddy is a local loop, a ridge holds things steady, a trough collects.
- **Named winds are the richest pool.** They are real words, short, distinctive, and each carries a direction, a place, and a character.
- **Cloud names compose.** The Latin roots combine by rule (*cirro-*, *alto-*, *strato-*, *cumulo-*, *nimbo-*), which makes them good material for invented names.
- **Sets give a naming scheme.** Cloud genera, the Beaufort scale, or a family of winds can name related projects or releases.
- **Watch the connotation.** Many weather words name destructive events. Say so in the notes when a name carries one.

## Clouds

Ten genera, by height:

| Level | Genera |
|---|---|
| High | Cirrus, Cirrocumulus, Cirrostratus |
| Middle | Altocumulus, Altostratus, Nimbostratus |
| Low | Stratus, Stratocumulus, Cumulus |
| Towering | Cumulonimbus |

Latin roots, usable alone or blended:

| Root | Meaning |
|---|---|
| *cirrus* | curl of hair |
| *cumulus* | heap |
| *stratus* | layer, spread out |
| *nimbus* | rain cloud |
| *altus* | high |
